# Sports Facility Booking Portal
Assignment 3 - End-to-End Portal Design (Python)

Group members: M.Mohsin , M.Hashim

This portal lets students book sports facilities (Badminton, Basketball, Futsal, Table Tennis) in one hour slots. The admin can see all bookings, all students and a report. Data is saved in text files.

How to run: open Sports_Facility_Portal.ipynb and run the cells from top to bottom, or copy whole code from sports_portal_code.txt
Type admin at the roll number prompt for the admin panel (password: admin123).
